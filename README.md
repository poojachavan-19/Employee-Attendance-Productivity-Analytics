# Employee Attendance & Productivity Analytics

## Project Overview

This project analyzes employee attendance and productivity data using Microsoft Excel.

## Tools Used

* Microsoft Excel
* PivotTables and PivotCharts
* Slicers
* Excel formulas and data cleaning

## Project Objectives

* Analyze employee attendance patterns.
* Compare productivity across job roles.
* Identify employee absence and leave trends.
* Present key insights using interactive charts and slicers.

## Key Features

* Data cleaning and formatting
* PivotTable-based analysis
* Interactive dashboard
* Charts and slicers for filtering data
* Key performance indicators (KPIs)

## Files Included

* Excel workbook containing the dataset, analysis, PivotTables, and dashboard.

## Conclusion

This project demonstrates how Excel can be used to analyze employee data and present meaningful insights for decision-making.
